# Kirundi News Topic Classification

Text classification for **Kirundi** (Ikirundi, ISO 639-3 `run`), the national language of Burundi.
The system assigns a Kirundi news article to a topic such as politics, sport, economy or health.

> Status: work in progress. Sections are filled in as each project stage is completed.
