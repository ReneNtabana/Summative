# Kirundi News Topic Classifier

Static web demo: a fine-tuned AfroXLMR-base model (int8 ONNX) runs in the browser with transformers.js
and classifies Kirundi news articles into 10 topics.
Code, experiments and report: https://github.com/ReneNtabana/Summative
